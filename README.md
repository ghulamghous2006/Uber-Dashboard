# Uber Ride Analytics Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard designed to analyse Uber ride bookings, revenue, trip distance, vehicle performance, and customer ratings. The dashboard provides business insights through interactive visualizations and KPI tracking.

## Key Features
- **Booking Analysis:** Tracks completed, lost, cancelled and incomplete bookings.
- **Revenue Analysis:** Monitors overall revenue and revenue by vehicle type.
- **Distance Analysis:** Analyses total and average ride distance.
- **Monthly Trends:** Visualizes booking and revenue trends across months.
- **Location Insights:** Identifies top pickup and drop-off locations.
- **Rating Analysis:** Tracks average customer and driver ratings.
- **Interactive Filters:** Supports monthly and quarterly analysis.

## Key Performance Indicators (KPIs)
- Completed Bookings: 23K
- Lost Bookings: 14K
- Revenue: 13M
- Total Distance: 625.62K
- Average Distance: 24.62

## Technologies Used
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Cleaning and Transformation
- Data Visualization
